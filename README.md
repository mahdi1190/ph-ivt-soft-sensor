## Quick start

1. Clone the repository and create the environment:
   ```bash
   git clone https://github.com/mahdi1190/ph-ivt-soft-sensor.git
   cd ph-ivt-soft-sensor
   conda env create -f environment.yml
   conda activate dd-repro
   ```
2. Reproduce the results:
   ```bash
   python code/soft_sensor_main.py   # UKF model outputs -> reports/
   python code/plot_rna_quad.py      # RNA figure
   python code/plot_pH_quad.py       # pH figure
   python code/plot_quad_NTP.py      # NTP panels
   ```

## Repository layout

```
code/                  # Python code for the models and the plotting scripts
notebooks/             # Legacy Jupyter notebook (early H–H model, superseded by code/hh_model.py)
data/                  # Experimental input data used by the code
figures/               # Figures generated by the plotting scripts
reports/               # Model outputs and tables generated by the code
.github/workflows/     # CI (import lint)
```
