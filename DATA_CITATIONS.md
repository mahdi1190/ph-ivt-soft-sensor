J. Cordiner and Z. Kis, *A soft sensor based on pH for real-time monitoring of
mRNA medicine production*, **Digital Discovery**, 2026, **5**(7), 2899–2914.
DOI: [10.1039/d5dd00417a](https://doi.org/10.1039/d5dd00417a)

## Code and data

M. Ahmed, S. Hamed, R. Cardoso, C. Kenyon, M. Pohare, M. Maamra, M. Dickman,
J. Cordiner and Z. Kis, *A soft sensor based on pH for real-time monitoring of
mRNA medicine production: code and data*, University of Sheffield, 2026.
Zenodo. DOI: [10.5281/zenodo.19629299](https://doi.org/10.5281/zenodo.19629299)

The DOI above is the concept DOI and always resolves to the most recent version.
To cite the exact version used in the article, use the version DOI
[10.5281/zenodo.19629300](https://doi.org/10.5281/zenodo.19629300) (v1.0.0).

Repository: https://github.com/mahdi1190/ph-ivt-soft-sensor
